# 🔤 What is a String in Java?

In Java, a **String** is an object that represents a **sequence of characters**. It's widely used to store and manipulate text.

---

## ✅ Example:

```java
public class StringExample {
    public static void main(String[] args) {
        String name = "Arpan";
        System.out.println("Hello, " + name + "!");
    }
}
```

---

## 🧠 Explanation:

- `String name = "Arpan";` → creates a string object.
- `+` is used to concatenate strings.

---

## 📌 Note:

Strings in Java are **immutable**, meaning once created, they cannot be changed.
